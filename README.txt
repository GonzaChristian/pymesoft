INCLUYE
- Navegación multipágina.
- Menú desplegable de soluciones.
- Modo claro/oscuro persistente.
- Fotografías externas de Unsplash mediante URL.
- Animaciones al hacer scroll.
- Efecto 3D suave en tarjetas.
- Contadores animados.
- Mockups visuales del producto creados con HTML/CSS.
- Diseño responsive.
- Formularios con validación visual (sin backend real todavía).
- Estructura pensada para clientes potenciales.

CÓMO PROBAR
1. Descomprime el ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Usa Live Server sobre index.html.
4. Navega entre todas las páginas.

IMPORTANTE
Las fotos se cargan desde Internet. Para una publicación real se recomienda descargar y optimizar
las imágenes dentro del proyecto, agregar dominio real, correo real y conectar el formulario
a un backend (por ejemplo PHP + MySQL).

NO SE INVENTARON TESTIMONIOS NI CLIENTES REALES.
